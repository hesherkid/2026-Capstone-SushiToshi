# Entra (Azure AD) Administration Guide

This document provides guidance and useful links for administering the Entra (Azure Active Directory) components of this application, including managing Staff and Admin groups.

---

## Managing Staff and Admin Groups

- **Staff Group:**  
  Add users who need standard staff permissions to this group.

- **Admin Group:**  
  Add users who require administrative privileges to this group.

> **Note:**  
> Users should be placed in only one group based on the permissions they require.

## Steps to Administer Groups

1. **Sign in to the [Azure Portal](https://portal.azure.com/).**
2. Navigate to **Microsoft Entra ID** (Azure Active Directory).
3. Select **Groups** from the left menu.
4. Search for the **Staff** or **Admin** group.
5. Click the group name to view details.
6. Use the **Members** tab to add or remove users as needed.
